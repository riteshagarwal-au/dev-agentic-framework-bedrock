# Work Order WO-022537 — Requirements Summary

**Reference:** MSA ID# CC MASM 00009595 2018 TR | Work Order ID#: WO-022537

**Date:** 2026-07-08

## 1. Scope of Work

Establish modernization requirements and operational processes for a multi-tenant platform with integrated AI capabilities. Key activities:

- Define and document requirements; advise on AWS general best practices for designing a multitenant platform architecture with integrated AI capabilities, incorporating Customer-selected use cases and modernization priorities.
- Design and deploy generative AI-enabled modernization patterns for:
  - Application assessment
  - Migration planning
  - Automated lifecycle management
  tailored to Customer-specified use cases.
- Review current state architecture and develop target state blueprints (quantity to be mutually agreed between AWS and Customer), incorporating:
  - Microservices
  - API modernization
  - Cloud-native patterns
- Document decisions across:
  - Technology stack selection
  - Security frameworks
  - Operational models
  - Governance structures
- Deploy the **In-Scope Framework** multi-agent components in Customer's non-production environment, including:
  - DevOps agents
  - Security agents
  - Application modernization agents
- Deploy against **one (1) application** in Customer's non-production environment.

## 2. Deliverables

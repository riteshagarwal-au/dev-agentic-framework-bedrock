###### **Summary for TAAF Deployment SOW**

This proposal outlines the engagement plan for deploying, securing, and operationalising a multi-agent Modernisation
framework within Telstra. The solution will leverage services like AWS Transform, Claude Code or Kiro, Amazon Bedrock
Agentcore, Enterprise AI Hub, and Accelerator Hub along with Security/DevOps agents. The engagement includes nonproduction pilots across key Modernisation use cases and concludes with comprehensive knowledge transfer and
enablement of Telstra teams.


Key Outcomes:


  - Modernisation Platform Operational – AWS Transform, Claude Code or Kiro, Amazon Bedrock Agentcore (multitenant), and Enterprise AI Hub deployed, security-approved, and production-ready with App/Cloud discovery and New
Relic NLQ observability integration


  - Non-Production Pilots Validated – Four pilots executed and validated — AMP Transit VPC→TGW migration (1 app),
CE→AMP LZ/Org move (2–4 apps), Java/Lambda runtime upgrade (1 app), and DevOps/Security agent pilot — with
documented outcomes and test results


  - Gen AI Accelerated to Production – Accelerator Hub deployed with 1–2 key Gen AI use cases identified, built, and
promoted to production, demonstrating tangible business value


  - Multi-Agent Framework Proven – Security and DevOps agents configured, piloted, and validated within the multiagent Modernisation framework, enabling scalable agent-driven operations


  - Self-Sufficiency Achieved – Platform team trained, tenant teams enabled via roadshows, and complete handover
documentation delivered for independent operation and extension of all capabilities
